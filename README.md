# Проект разработка LM ("Образовательные модули") для онлайн-обучения


## Описание:
Проект разработка LM ("Образовательные модули") для онлайн-обучения это дипломная работа студента


## Установка:
1. Клонируйте репозиторий 
``` git clone nttps:https://github.com/elenapantsurkina/Learning_modules```


## Зависимости
- python 3.12
- django 5.1.6
- 
виртуальное окружение poetry 
- все зависимости подробно описаны в pyproject.toml
- redis
- celery

## Использование:
Установите Docker.
Для запуска проекта с использованием Docker Compose выполните следующую команду: docker-compose up --build

Для проверки работы приложения на localhost выполните команду `python manage.py runserver`


## Функционал:
Созданы приложения "users" и "lm"
Подключена БД
Авторизация пользователей осуществляется по по email.
Определены права доступа
В приложении lm создана модель с полями : порядковый номер, название, описание
Реализована CRUD для моделей
Реализована пагинация 
Покрытие тестов 90%.


## Документация:
Подключен и настроен вывод документации для проекта с использованием Swagger.
